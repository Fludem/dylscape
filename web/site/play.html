Play on Onyx

You do not need a proxy, a loopback alias, or a copy of the game cache. The client is stock RuneLite with a handful of byte-level patches so it talks to our world instead of Jagex's, and the ~190 MB cache streams from the server the first time you launch it.

World address

rsps.onyxleeds.co.uk:43594

Requirements

Windows 10 or 11 (64-bit), or a Mac with Apple Silicon (M1 or newer). Java is included, so there is nothing else to install. About 400 MB of disk for the cache.

Download

Download for Windows Download for Mac (Apple Silicon)

Unzip it anywhere, then double-click Onyx.bat on Windows or Onyx.command on a Mac.

Getting started

  1. Get the client

    Download the zip for your computer above and unzip it anywhere. It is a patched RuneLite pinned to the exact version that matches this server, so a newer RuneLite from the official site will not connect. It keeps its own settings and never touches a normal RuneLite install.

  2. Launch it

    Double-click Onyx.bat on Windows or Onyx.command on a Mac.

    Mac: the first time, macOS says it cannot be opened because the file is not signed. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway. Windows: if a “Windows protected your PC” box appears, click More info → Run anyway. Either way, it only happens once.

  3. Make an account

    There is no registration page. Type any username and password at the login screen and the account is created on the spot, with the password hashed the same way a real one would be. Choose carefully — the username is yours.

  4. Choose your account type and rate

    The first time you log in you pick an account type and an experience rate. Both are permanent. The faster the experience, the smaller the drop-rate bonus.

  5. Play

    Twenty of the game's twenty-three skills are live, monsters use wiki-accurate drop tables, and there is a teleport menu to get you around. Herblore, Slayer and Runecraft are not implemented — see the guides for the full picture.

A note on the cache. The first launch downloads about 190 MB from the server before you reach the login screen. It only happens once.
Don't use the world switcher. RuneLite lists the real game's worlds there, and hopping to one drops you out of Onyx.
